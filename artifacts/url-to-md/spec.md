## 개요

웹 페이지 URL을 Markdown으로 변환해 LLM에 바로 넘길 수 있는 단일 페이지 도구. 사용자는 URL 하나로 본문을 추출하고, 복사·다운로드·ChatGPT·Claude 열기로 내보낸다.

## 범위

### 포함

- URL 입력 및 Markdown 변환
- 결과 확인 (페이지 제목·저자 헤더 + 렌더링된 Markdown)
- 내보내기: 복사하기, .md 다운로드, ChatGPT/Claude 새 탭으로 열기
- 프롬프트 선택 (프리셋 3개 + 직접 입력)
- 원인별 에러 메시지
- 시스템 설정 기반 다크모드 자동 적용

### 제외

- 모바일 지원 — 이번 스코프 아님, 데스크톱 전용
- 프롬프트 저장·히스토리 — 직접 입력은 1회용, 영속성 없음
- 변환 이력·북마크 — 향후 검토
- 로그인·사용자 계정 — 인증 없는 공개 도구

## 시나리오

### 1. URL 입력 후 변환 성공

- **Given** — URL 입력창이 비어 있는 초기 화면
- **When** — 유효한 URL을 입력하고 변환 버튼 클릭
- **Then** — 로딩 인디케이터가 나타났다가 사라지고, 페이지 제목과 저자 정보가 헤더로, 추출된 본문이 렌더링된 Markdown으로 표시된다

성공 기준:
- [ ] 변환 버튼 클릭 직후 로딩 인디케이터가 보인다
- [ ] 변환 완료 후 페이지 제목 텍스트가 결과 영역 상단에 표시된다
- [ ] 변환 완료 후 Markdown 본문이 렌더링된 형태로 표시된다

---

### 2. URL 입력창 초기화

- **Given** — URL이 입력된 상태 (변환 결과 유무 무관)
- **When** — 지우기(X) 버튼 클릭
- **Then** — URL 입력창만 비워지고, 이전 변환 결과는 그대로 유지된다

성공 기준:
- [ ] 지우기 버튼 클릭 후 URL 입력창이 빈 상태가 된다
- [ ] 지우기 전에 결과가 표시돼 있었다면, 결과 영역은 변하지 않는다

---

### 3. 새 URL로 재변환

- **Given** — 이전 변환 결과가 표시된 상태에서 URL 입력창에 다른 URL이 입력됨
- **When** — 변환 버튼 클릭
- **Then** — 새 URL의 결과로 교체된다

성공 기준:
- [ ] 재변환 완료 후 결과 영역에 새 페이지 제목이 표시된다
- [ ] 이전 페이지 제목은 더 이상 보이지 않는다

---

### 4. 복사하기

- **Given** — 변환 결과가 표시된 상태
- **When** — "복사하기" 버튼 클릭
- **Then** — 순수 Markdown 텍스트가 클립보드에 복사되고, 버튼 레이블이 "복사됨!"으로 잠시 바뀐 뒤 원래 상태로 돌아온다

성공 기준:
- [ ] 복사하기 버튼 클릭 후 버튼 레이블이 "복사됨!"으로 변한다
- [ ] 클립보드 내용에 선택된 프롬프트 텍스트가 포함되지 않는다
- [ ] 클립보드 내용이 결과 영역의 Markdown과 동일하다

---

### 5. .md 파일 다운로드

- **Given** — 변환 결과가 표시된 상태
- **When** — ".md 다운로드" 버튼 클릭
- **Then** — 순수 Markdown 내용이 담긴 .md 파일이 다운로드된다

성공 기준:
- [ ] 다운로드된 파일의 확장자가 `.md`다
- [ ] 파일 내용에 선택된 프롬프트 텍스트가 포함되지 않는다
- [ ] 파일 내용이 결과 영역의 Markdown과 동일하다

---

### 6. 프롬프트 없이 ChatGPT / Claude로 열기

- **Given** — 변환 결과가 표시되고, 프롬프트가 선택되지 않은 상태
- **When** — "ChatGPT로 열기" 또는 "Claude로 열기" 버튼 클릭
- **Then** — Markdown 내용이 클립보드에 복사되고, 새 탭에서 각 서비스가 열린다

성공 기준:
- [ ] 버튼 클릭 후 새 탭이 열린다
- [ ] 클립보드에 Markdown 내용이 복사된다
- [ ] 현재 탭의 상태는 변하지 않는다

---

### 7. 프리셋 프롬프트와 함께 ChatGPT / Claude로 열기

- **Given** — 변환 결과가 표시되고, 프리셋 프롬프트("요약해줘" / "한국어로 번역해줘" / "쉽게 설명해줘") 중 하나가 선택된 상태
- **When** — "ChatGPT로 열기" 또는 "Claude로 열기" 버튼 클릭
- **Then** — 클립보드에 "[선택한 프롬프트 텍스트]\n\n[Markdown 내용]" 형식으로 복사되고, 새 탭에서 서비스가 열린다

성공 기준:
- [ ] 클립보드 내용이 선택된 프롬프트 텍스트로 시작한다
- [ ] 프롬프트 텍스트 이후 Markdown 내용이 이어진다

---

### 8. 직접 입력 프롬프트와 함께 열기

- **Given** — 변환 결과가 표시되고, "직접 입력" 옵션이 선택되어 텍스트 입력창이 보이며 커스텀 프롬프트가 입력된 상태
- **When** — "ChatGPT로 열기" 또는 "Claude로 열기" 버튼 클릭
- **Then** — 클립보드에 "[커스텀 프롬프트]\n\n[Markdown 내용]" 형식으로 복사되고, 새 탭에서 서비스가 열린다. 다음 변환 시 직접 입력 텍스트는 초기화된다

성공 기준:
- [ ] "직접 입력" 선택 시 텍스트 입력창이 나타난다
- [ ] 클립보드 내용이 입력한 커스텀 프롬프트 텍스트로 시작한다
- [ ] 다음 변환 완료 후 직접 입력창이 비어 있다

---

### 9. 유효하지 않은 URL 입력

- **Given** — URL 입력창에 URL 형식이 아닌 텍스트가 입력된 상태
- **When** — 변환 버튼 클릭
- **Then** — "유효하지 않은 URL입니다" 에러 메시지가 표시되고 변환이 진행되지 않는다

성공 기준:
- [ ] 에러 메시지가 입력창 근처에 표시된다
- [ ] 로딩 인디케이터가 나타나지 않는다
- [ ] 이전 변환 결과가 있다면 그대로 유지된다

---

### 10. URL 접근 불가

- **Given** — 유효한 URL 형식이 입력된 상태
- **When** — 존재하지 않거나 접근이 차단된 URL로 변환 시도
- **Then** — "페이지에 접근할 수 없습니다" 에러 메시지가 표시된다

성공 기준:
- [ ] 로딩 인디케이터가 사라진 뒤 에러 메시지가 표시된다
- [ ] 결과 영역에 빈 Markdown이 표시되지 않는다

---

### 11. 본문 추출 실패

- **Given** — 유효한 URL이 입력된 상태
- **When** — 접근은 되지만 추출 가능한 본문이 없는 페이지(로그인 벽, JS 전용 SPA 등)로 변환 시도
- **Then** — "본문을 추출할 수 없습니다" 에러 메시지가 표시된다

성공 기준:
- [ ] 로딩 인디케이터가 사라진 뒤 에러 메시지가 표시된다
- [ ] 결과 영역에 빈 내용이 렌더링되지 않는다

---

## 불변 규칙

**내보내기 데이터 일관성**
복사하기·.md 다운로드는 항상 순수 Markdown만 포함한다. 선택된 프롬프트는 ChatGPT·Claude로 열기 경로에만 반영된다. 어떤 내보내기 경로도 이 규칙의 예외가 없다.

**다크모드**
배경색·텍스트색 등 모든 색상은 OS/브라우저의 시스템 다크모드 설정을 자동으로 따른다. 앱 내 별도 토글이 없다.
